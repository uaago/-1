# Colab 训练示例实施计划

**目标：** 在独立本地项目中提供两个无需下载数据的训练任务，验证上传、云端执行、Drive 备份和断点续训。

**架构：** 本地代码通过文件夹上传或 ZIP 同步到 `/content/colab_training_demo`；固定启动笔记本启动独立 Python 进程。训练读写临时磁盘，完整检查点、指标和代码快照定期备份到 Drive 的独立实验目录。

**技术：** Python、PyTorch、NumPy、Matplotlib、JSON 配置；标准库文件复制、SHA-256 完整性验证。

## 方案选择

- 使用合成回归和二维分类任务，避免下载数据时的网络依赖；真实图像数据集可在流程验证后替换。
- 首次用文件夹上传，提供 ZIP 打包作为备用；Git 同步适合后续正式项目。
- 以完整 epoch 为恢复边界，演示先完成 3 轮，再从保存状态续到 12 轮。
- 使用版本化检查点及最后写入的哈希清单，忽略临时文件；备份失败不删除本地结果，后续检查点重试。

## 实施步骤

1. 创建 `colab_training_demo/` 包、`configs/`、依赖列表和本地 ZIP 打包脚本；保留原有文件。
2. 实现可复现数据生成、MLP、训练入口及配置验证。
3. 实现模型、优化器、调度器、训练进度和 Python/NumPy/Torch/CUDA/采样器随机状态保存与恢复。
4. 实现本地完整检查点及 Drive 复制校验、最近版本保留、日志快照和最佳模型导出。
5. 创建有序启动笔记本：环境自检、挂载验证、定位上传代码、依赖检查、分段训练、续训、指标和恢复指导。
6. 编写中文 README，提供 VS Code 上传与网页 ZIP 备用路线，以及断线排查和防止重复启动的说明。
7. 验证 CPU 短训练、断点续训与连续训练的一致性、损坏备份回退、备份失败后的本地保留、代码/配置不匹配拒绝恢复；检查笔记本和 ZIP。

## 验收边界

本机可以验证训练和文件备份逻辑；用户需要在自己的 Colab 会话中完成 Google 登录、GPU 分配、Drive 授权及真实挂载验证。不承诺运行时永不回收，也不承诺不同 CUDA/软件环境逐位一致。
